# 📘 Assignment: Lists, Dicts, and Data Structures

## 🎯 Objective

Master Python's core collection types—lists, dictionaries, and tuples—and learn how to organize and manipulate data effectively. You'll practice choosing the right data structure for different problems and perform common operations like filtering, sorting, and searching.

**Skills practiced:** Lists and list comprehensions, dictionaries and key-value operations, tuples and immutability, nested data structures, iteration, data organization

## 📝 Tasks

### 🛠️ Work with Lists and List Operations

#### Description
Create a program that demonstrates fundamental list operations and manipulation techniques.

#### Requirements
Completed program should:

- Create lists and access elements by index (including negative indexing)
- Add, remove, and modify list elements using append(), insert(), remove(), pop()
- Use list slicing to extract sub-lists
- Sort and reverse lists
- Use built-in functions: len(), min(), max(), sum()
- Write at least one list comprehension to transform or filter data
- Example: Create a list of numbers and use comprehension to get only even numbers

### 🛠️ Understand Dictionaries and Key-Value Pairs

#### Description
Build programs that use dictionaries to organize and retrieve data efficiently.

#### Requirements
Completed program should:

- Create dictionaries with multiple key-value pairs
- Access, add, and modify dictionary values
- Use get() method to safely retrieve values
- Iterate through dictionary keys and values
- Demonstrate checking if a key exists using `in` operator
- Build a dictionary from user input or a list
- Example: Create a dictionary of student names and grades, then calculate average

### 🛠️ Work with Nested Data Structures

#### Description
Practice organizing complex data using nested lists and dictionaries.

#### Requirements
Completed program should:

- Create nested lists (list of lists) and access nested elements
- Create nested dictionaries (dictionary with dictionary values)
- Mix lists and dictionaries (e.g., list of dictionaries)
- Iterate through nested structures properly
- Perform operations on nested data (search, filter, modify)
- Example: Store a list of student records where each record is a dictionary with name, age, grades

### 🛠️ Build a Data Management System

#### Description
Create a comprehensive program that combines lists, dictionaries, and operations to manage a real-world dataset.

#### Requirements
Completed program should:

- Define a data structure to store multiple records (e.g., contacts, inventory, employees)
- Implement functions to add, remove, and update records
- Implement search functionality (find by name, ID, or other fields)
- Sort records by different fields
- Calculate statistics (count, average, min, max) on numeric fields
- Display data in a readable format
- Example: Build a contact manager or student grade tracker
